# Музыка за баллы

Заказ музыки за баллы канала Twitch из **Яндекс Музыки, YouTube и Spotify** с оверлеем для OBS.

Зритель выкупает награду, пишет «Исполнитель - Название» или вставляет ссылку на трек, и трек встаёт в очередь
и играет на компьютере стримера. В OBS видны обложка, название, кто заказал, прогресс и очередь, а в чат Twitch
приходит ответ: заказ принят или почему нет. Если заказ выполнить нельзя, выкуп отменяется и баллы возвращаются зрителю.

## Возможности

- Заказы по названию и по ссылкам: Яндекс Музыка, YouTube (включая YouTube Music и Shorts), Spotify.
- Награда за баллы создаётся автоматически. Название, цена и подсказка меняются из панели и сразу применяются на Twitch.
- Ответы в чат Twitch о принятых заказах и причинах отказа, тексты настраиваются.
- Лимиты: длина очереди, число треков от одного зрителя, максимальная длина трека, запрещённые слова.
- Чёрный список зрителей и треков.
- Веб-панель управления: плеер, очередь, громкость, журнал заказов, все настройки без правки файлов.
- Оверлей для OBS с живым предпросмотром в панели (цвета, положение, размер, шрифт), а также текстовый файл
  `now_playing.txt` для источника «Текст».
- Следующий трек скачивается, пока играет текущий, поэтому пауз между треками почти нет.
- Сборка в `.exe` для Windows.

## Требования

### Система
- **Windows 10/11** (основная платформа: есть `run.bat` и сборка в `.exe`). Linux и macOS работают через `run.sh`.
- **Python 3.10 или новее** (проверено на 3.12 и 3.13). При установке на Windows отметьте «Add Python to PATH».
- Интернет и звуковое устройство: музыка играет на компьютере, где запущена программа.
- **OBS Studio 28+**: источник «Браузер» для оверлея и «Захват звука приложения» для музыки.

### Для заказов с YouTube
- **Deno** (рекомендуется) или Node.js. С конца 2025 года без внешнего JavaScript-рантайма `yt-dlp` может не скачивать
  с YouTube. Установка: `winget install DenoLand.Deno` или `install_deno.bat` из папки проекта (скачивает официальный
  Deno с GitHub в `%USERPROFILE%\.deno\bin` и добавляет его в PATH).
- `ffmpeg` ставится автоматически вместе с зависимостями (пакет `imageio-ffmpeg`).

### Аккаунты и ключи
- **Twitch:** канал со статусом Affiliate или Partner (баллы канала есть только у них) и приложение на
  [dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps): адрес перенаправления
  `http://localhost:4343/callback`, тип клиента Confidential.
- **Яндекс Музыка** (необязательно): токен аккаунта, как получить — на вкладке «Подключения» в панели.
  Без подписки Яндекс Плюс треки могут играть только фрагментом. Если Яндекс не нужен, отключите его на вкладке
  «Заказы», и заказы будут идти через YouTube.
- **Spotify:** ничего не нужно.

### Python-пакеты

Ставятся автоматически при первом запуске `run.bat` / `run.sh` или вручную: `pip install -r requirements.txt`.

| Пакет | Зачем |
|---|---|
| `aiohttp` | веб-панель, оверлей для OBS, Twitch API |
| `aiofiles` | загрузка треков из Яндекс Музыки |
| `yandex-music` | поиск и загрузка из Яндекс Музыки |
| `yt-dlp[default]` | поиск и загрузка с YouTube |
| `imageio-ffmpeg` | ffmpeg для перевода звука YouTube в mp3 |
| `pygame` | воспроизведение музыки |
| `python-dotenv` | чтение необязательного файла `.env` |
| `certifi` | сертификаты для HTTPS (нужны, например, для ссылок Spotify) |

## Установка и запуск

```
git clone https://github.com/beg1nnner/yamusic-points.git
cd yamusic-points
run.bat
```

1. Первый запуск создаст виртуальное окружение `.venv` и поставит зависимости. `run.bat` при каждом запуске
   обновляет `yt-dlp`, потому что YouTube часто меняется.
2. Откроется **панель** `http://127.0.0.1:8080/control`. На вкладке «Подключения» введите Twitch Client ID/Secret
   и токен Яндекс Музыки и нажмите «Сохранить», программа продолжит запуск сама.
3. Откроется окно Twitch: разрешите доступ (баллы канала и сообщения в чат).
4. Награда за баллы создастся на канале автоматически.

Проверка без Twitch: `python main.py --no-twitch`, заказы вводятся в консоли. Тестовые заказы можно делать и в панели,
на вкладке «Плеер»: они не тратят баллы.

## Откуда можно заказывать

Зритель пишет «Исполнитель - Название» или вставляет ссылку на **отдельный трек**:

| Источник | Что принимается |
|---|---|
| Яндекс Музыка | ссылки `music.yandex.ru/.../track/...` |
| YouTube | `youtube.com/watch?v=`, `youtu.be/`, `music.youtube.com`, Shorts. Плейлисты и прямые трансляции не принимаются |
| Spotify | ссылки `open.spotify.com/track/...` |
| Обычный текст | поиск сначала в одном источнике, затем в другом (порядок и включение источников настраиваются на вкладке «Заказы») |

**Про Spotify.** Spotify не отдаёт звук (он защищён DRM). Поэтому по ссылке программа читает название, исполнителя
и длительность трека со страницы Spotify для встраивания (она работает и из России, где обычная страница трека
приходит пустой), а затем ищет **тот же трек** в Яндекс Музыке или на YouTube. Длительность должна совпасть
с точностью до 10 секунд для Яндекса и 20 для YouTube, иначе трек не принимается, чтобы не включить не ту песню.
Ключи Spotify API не нужны.

Проверить, что для YouTube всё на месте (yt-dlp, ffmpeg, Deno, доступ к YouTube), можно кнопкой
**«Проверить YouTube»** на вкладке «Подключения».

## Панель `/control`

| Вкладка | Что внутри |
|---|---|
| Плеер | что играет, пропуск, пауза, громкость, очередь (можно убрать трек), тестовый заказ, журнал заказов и отказов |
| Заказы | источники, название, цена и подсказка награды (меняются на Twitch сразу), лимиты, запрещённые слова, сообщения в чат |
| Чёрный список | блокировка зрителей и треков, разблокировка, добавление вручную |
| Оверлей | цвета, прозрачность, положение, размер, шрифт, что показывать, **живой предпросмотр**, текстовый файл для OBS |
| Подключения | ключи Twitch, токен Яндекса, адрес и порт сервера, проверка YouTube, тест чата, повторный вход в Twitch |

Все настройки применяются сразу после «Сохранить». Перезапуск нужен только при смене порта или адреса сервера,
а также Twitch Client ID/Secret, если Twitch уже подключён. Настройки хранятся в `settings.json`. Файл `.env`
необязателен (пример в `.env.example`): если он есть, из него берутся значения по умолчанию.

## Сообщения в чате Twitch

Программа пишет в чат, принят ли заказ и почему он не принят (трек не найден, очередь полна, лимит,
слишком длинный трек, трек или слово в чёрном списке, дубликат). Тексты и включение настраиваются на вкладке
«Заказы» в разделе «Сообщения в чате». Подстановки: `{user}`, `{artists}`, `{title}`, `{position}`, `{reason}`.

- Сообщения идут **от имени аккаунта стримера**.
- Если вход в Twitch был выполнен в версии без сообщений в чат, при запуске откроется окно Twitch для выдачи доступа.
  Позже это можно сделать кнопкой «Войти в Twitch заново» на вкладке «Подключения», там же есть тестовое сообщение.
- Для зрителей из чёрного списка в чат ничего не пишется.
- Сообщения уходят с паузой около секунды, чтобы не упереться в лимиты Twitch. Если AutoMod или правила канала
  отклонят текст, ошибка появится в журнале панели.

## Чёрный список

- **Из очереди и «Сейчас играет»:** кнопки «Блок. трек» и «Блок. зрителя». Блокировка сразу убирает заказы
  из очереди, а если играет заблокированное, трек пропускается.
- **Из журнала:** рядом с заказом или отказом есть кнопка «Блок. зрителя».
- **Вручную:** вкладка «Чёрный список». Зрителя добавляют по нику из адреса канала, трек по ссылке
  или запросу «Исполнитель - Название».
- Заказ заблокированного зрителя или трека отклоняется, баллы возвращаются. Для зрителя уведомление
  в OBS не показывается, для трека показывается.
- Блокируется конкретная версия трека. Исполнителя целиком можно закрыть через «Запрещённые слова».

## Настройка OBS

1. **Источники → + → Браузер**, адрес `http://127.0.0.1:8080/`, размер **700×460**, фон прозрачный.
   Положение и размер карточки настраиваются во вкладке «Оверлей».
2. **Звук.** Музыка играет на вашем ПК. Добавьте источник **«Захват звука приложения»** (Windows, OBS 28+)
   и выберите `python.exe` (или `MusicForPoints.exe`, если запускаете собранную версию),
   либо используйте захват звука рабочего стола.
3. Панель можно добавить в OBS как док: **Док-панели → Пользовательские док-панели браузера**,
   адрес `http://127.0.0.1:8080/control`.
4. **Текстовый источник.** Добавьте «Текст (GDI+)», включите «Читать из файла» и выберите `now_playing.txt`
   из папки программы (полный путь есть в консоли при запуске и во вкладке «Оверлей»).

## Сборка в .exe (Windows)

1. Запустите `build_exe.bat`. Он сам поставит PyInstaller и соберёт программу.
2. Результат лежит в `dist\MusicForPoints\`. Раздавайте **всю папку** целиком (лучше в zip),
   запускать нужно `MusicForPoints.exe` внутри неё.
3. Настройки, вход в Twitch и чёрный список хранятся рядом с `.exe` (`settings.json`, `tokens.json`,
   `blocklist.json`) и сохраняются при пересборке. Не кладите папку в `Program Files`: туда нельзя писать
   без прав администратора.

В `.exe` вшиваются `yt-dlp`, `ffmpeg` и сертификаты, но **Deno или Node.js нужно ставить на каждом компьютере
отдельно**. `yt-dlp` внутри готового `.exe` не обновляется: если YouTube перестал работать, пересоберите программу.

Окно консоли оставлено намеренно: в нём видны журнал и ошибки. Антивирусы иногда ругаются на `.exe`
из PyInstaller, это ложное срабатывание. Помогает цифровая подпись файла.

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | запуск, связывает части; ждёт настроек, если ключей ещё нет |
| `config.py` | описание всех настроек, проверка значений, сохранение в `settings.json` |
| `twitch.py` | вход, награда за баллы, EventSub, отмена/принятие выкупов, сообщения в чат |
| `sources.py` | единая модель трека, разбор ссылок, поиск и загрузка: Яндекс, YouTube (`yt-dlp`), Spotify |
| `ym.py` | работа с Яндекс Музыкой (`yandex-music`) |
| `radio.py` | очередь, лимиты, предзагрузка, воспроизведение (pygame) |
| `blocklist.py` | чёрный список зрителей и треков (`blocklist.json`) |
| `messages.py` | шаблоны сообщений для чата |
| `netssl.py` | проверка HTTPS-сертификатов (системные + `certifi`) |
| `overlay_server.py` | сервер оверлея, панели и API настроек |
| `overlay/index.html` | оверлей для OBS |
| `overlay/control.html` | панель управления и настроек |
| `run.bat`, `run.sh` | запуск из исходников |
| `build_exe.bat` | сборка `.exe` |
| `install_deno.bat`, `install_deno.ps1` | установка Deno для YouTube |

## Если что-то не работает

- **Заказы с YouTube не работают.** Нажмите «Проверить YouTube» на вкладке «Подключения»: кнопка покажет, чего
  не хватает. Чаще всего помогает установка Deno и обновление `yt-dlp`: `.venv\Scripts\pip install -U "yt-dlp[default]"`.
- **«Не удалось получить видео с YouTube».** Видео может быть приватным, удалённым, с ограничением по возрасту
  или региону. Подробная причина пишется в журнал панели и в консоль.
- **Ссылка Spotify не читается.** Программа берёт данные со страниц Spotify. Если Spotify их изменит, чтение
  сломается, тогда такой трек можно заказать по названию.
- **Ошибка загрузки из Яндекс Музыки.** Обновите библиотеку: `pip install -U yandex-music aiofiles`.
- **«Награда уже есть на канале, но создана не этим приложением».** Twitch разрешает приложению управлять только
  своими наградами. Удалите награду с таким названием на Twitch или смените название на вкладке «Заказы».
- **Нет звука.** Проверьте устройство вывода Windows и громкость в панели.
- **Сменить аккаунт Twitch.** Вкладка «Подключения» → «Выйти из Twitch», затем перезапуск.

## Важно

Не публикуйте `settings.json`, `tokens.json`, `blocklist.json` и `.env`: в них ключи Twitch и токен Яндекса.
Они перечислены в `.gitignore`.

Программа использует неофициальный API Яндекс Музыки и скачивает звук с YouTube. Это, как и трансляция музыки
на стриме, может нарушать правила сервисов и права правообладателей (на Twitch возможны жалобы DMCA).
Ответственность за использование лежит на пользователе.
